## القسم الخامس عشر: الأمان وأخطاء شائعة

## حقن SQL

أخطر غلطة: تبني الاستعلام بتجميع نصوص. جربنا ده بجد، في قاعدة بيانات ذاكرة مخترعة. كتبنا اسم فرع فيه رموز خاصة، فيه فاصلة منقوطة وأمر حذف جدول، ولصقناه جوه نص الاستعلام، وشغلناه بـ cur.executescript. وانتبه للتفصيلة دي: executescript بتشغل أكتر من أمر في مرة واحدة. بعد التشغيل، سألنا قاعدة البيانات عن جداولها: جدول المبيعات اختفى! فضل جدول الفروع بس. ده اسمه SQL injection.

## وبـ cur.execute العادية؟

الدوكيومنتيشن الرسمية بتاعة Python بتقول عن execute: Execute a single SQL statement, optionally binding Python values using placeholders. وبتقول: Use executescript to execute multiple SQL statements. يعني execute العادية بترفض أمرين. وجربنا نفس الاسم بـ execute العادية: رجع ProgrammingError، وجدول المبيعات فضل موجود.

بس الخطر لسه موجود حتى مع execute العادية. كتبنا اسم فيه شرط OR واحد يساوي واحد، فبقى الشرط صح في كل الحالات، ولصقناه في النص. الاستعلام رجع الفروع التلاتة كلها بدل ولا فرع.

## الحل

الاستعلام بعلامة استفهام، والقيمة بتتبعت لوحدها. عملنا كده مع الاسم ده: القاعدة بحثت عن فرع بالاسم ده حرفياً ورجعت صفر. وعملنا كده مع اسم OR: رجعت قايمة فاضية. وأنا بنصحك بالطريقة دي، لأي قيمة جاية من مستخدم أو ملف.

## أخطاء تانية

الأول: الربط على عمود غلط، فتتكرر الصفوف. عدد الصفوف بعد أي ربط لازم تعده.

التاني: تنسى إن الربط العادي بيخفي اللي مالوش مقابل.

التالت: تستخدم select نجمة على جدول ضخم.

الرابع: تجمع الداتا كلها لـ pandas وهي بالملايين، بدل ما تخلي قاعدة البيانات تلخص.

تذكير: كل الأرقام في الدرس مخترعة، وكل اللي اتشغل هو sqlite بس.
