Excel C1 video 1 lesson files.
Run everything from THIS folder (the one that holds assets, run, data, lab). Paths inside the scripts are relative.
Setup: Python 3.13, then: pip install pandas==3.1.1 openpyxl==3.1.5 ; LibreOffice 26.8.3.1 is used for recalculation (soffice on PATH).
Example: python assets/g1.py   (compare the printed output with run/g1.out)
Table example: python assets/i1_table_run.py  -> run/i1_table_run.out
Lab: python lab/make_lab2.py -> lab/lab2.xlsx ; log in run/lab2.out
Versions used: run/versions.out. All results were produced with Python and LibreOffice, not Microsoft Excel. All data is made up.
