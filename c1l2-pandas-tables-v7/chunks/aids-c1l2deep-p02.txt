## خريطة الدرس

هنمشي في ترتيب واضح. هنبدأ بالـ Series، وهو عمود واحد. بعدين الـ DataFrame، وهو الجدول. بعدين إزاي نختار أعمدة وصفوف، ونعمل أعمدة جديدة. بعدين ملخصات سريعة وتجميع، وبعدين القيم الناقصة. وبعدين قراءة وكتابة ملف CSV، ودمج جدولين، والتعامل مع النصوص. وفي الآخر الأخطاء الشائعة وتمرين.

لو عندك Python وpip، التنصيب بأمر pip install pandas. أنا شغلت الأمثلة بنسخة three point one point one من pandas. وما جربتش نسخ أحدث.

والمكتبة بنستورتها بسطر import pandas as pd، والاسم pd اتفق عليه الناس زي np تماماً.
