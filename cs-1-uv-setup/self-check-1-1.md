# Lesson 1.1 self-check (10 questions, answers below). Informal self-check, not an official test. It only tests the basic Python, terminal and Git skills the lesson needs.
1. What does `print(type(3.0))` show?
2. What does `len([1, 2, 3])` return?
3. What is the output of `for i in range(3): print(i)`?
4. Write a function `double(n)` that returns n times two.
5. How do you read the first element of a list called `xs`?
6. What does `"abc".upper()` return?
7. What happens when you run `int("x")`?
8. What does `if x > 3:` need on the next line to work?
9. Which Linux terminal command lists the files in the current folder?
10. What does `git status` show?
Answers: 1 <class 'float'>. 2 three. 3 zero, one, two on separate lines. 4 def double(n): return n * 2. 5 xs[0]. 6 "ABC". 7 a ValueError. 8 an indented block. 9 ls. 10 the changed, staged and untracked files of the repo.
Scoring: 8 or more correct = continue. Fewer: review the Python basics and the terminal/Git parts of the Data Engineering playlist first, then return.
