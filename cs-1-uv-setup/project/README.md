# inventory-tool

A tiny tool that adds up the value of a stock list. The data in the example is invented for teaching.

## Requirements
- uv (we used 0.13.8)
- Python 3.14 (uv picks it from .python-version)

## Run
    uv run inventory-tool

## Test
    uv run --locked pytest -q

## Versions we used
uv 0.13.8, CPython 3.14.10, pytest 9.2.0
