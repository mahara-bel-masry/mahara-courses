# تمارين الدرس: جيت من الصفر

خمسة تمارين على ريبو تجريبي صغير. كل الحلول منفذة فعلًا في `exercises-session.txt`. نفذها في مجلد فاضي جوه `/tmp` أو أي مكان تقدر تمسحه بعدين.

ملاحظة: في الحلول هتلاقي أحيانًا `RC=$?` بعد أمر: ده بيحفظ كود خروجه في متغير نطبعه بعدين. انسخ السطرين مع بعض.

## تمرين 1: ريبو من الصفر بتلات كوميتات

اعمل ريبو جديد فيه ملف `notes.md`، وسجل تلات كوميتات متتالية: إنشاء الملف، إضافة قسم، إضافة سطر يوميات.

الحل المنفذ (ملخص): `git init -b main` ثم إعداد الهوية المحلية، ثم تلات جولات من: تعديل الملف بـ `printf` ثم `git add notes.md` ثم `git commit -m "..."`. الناتج الحقيقي:

```
b7a22b9 docs: first diary entry
b33fbc3 docs: learning diary section
250992b init: notes file
```

## تمرين 2: فرع ميزة ودمج سريع

اعمل فرع `feature/todo`، ضيف فيه قسم مهام للملف، اعمل كوميت، ارجع للأساسي وادمج.

النتيجة الحقيقية: `Updating b7a22b9..863718f` ثم `Fast-forward`. الأساسي مكانش اتفرع، فجيت حرك المؤشر بس من غير كوميت دمج.

## تمرين 3: تعارض متعمد وحله بإيدك

غير السطر الأول من `notes.md` على فرع `feature/title-ar` لصيغة، وعلى الأساسي لصيغة تانية، وجرب تدمج.

النتيجة الحقيقية: `CONFLICT (content): Merge conflict in notes.md`. والملف ظهر فيه العلامات:

```
<<<<<<< HEAD
# يوميات التعلم
=======
# يومياتي بالعربي
>>>>>>> feature/title-ar
```

الحل المنفذ: استبدلنا العلامات بسطر موحد `# يومياتي لتعلم جيت`، ثم `git add notes.md` ثم `git commit -m "merge: unified title"`. والشجرة النهائية فيها كوميت الدمج بأبوين.

## تمرين 4: استبعاد مجلد بيانات

اعمل مجلد `data` فيه ملف CSV، شوف `git status --short`، وبعدين استبعده.

النتيجة الحقيقية: قبل الاستبعاد ظهر `?? data/`، وبعد كتابة `data/` في `.gitignore` اختفى من القايمة وظهر `?? .gitignore` بس. ده إثبات إن الاستبعاد شغال.

## تمرين 5: مراجعة التاريخ

من نفس الريبو: شوف تفاصيل كوميت الدمج بـ `git show --stat HEAD~1` (لاحظ سطر `Merge:` وفيه أبوين)، وقارن بين لقطتين بـ `git diff HEAD~2 HEAD -- notes.md` وشوف تغير سطر العنوان بالألوان.

## تحدي إضافي (من غير حل مسجل)

ارجع للريبو اللي بنيناه في الدرس (logtool) واعمل فرع جديد يضيف قسم جديد للتقرير، مثل عدد صفحات 404، وادمجه. لو حصل تعارض، حله بنفس خطوات الدرس.
