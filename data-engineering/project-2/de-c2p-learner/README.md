# أداة ETL للأوردرات — مشروع كورس بايثون لمهندس البيانات

أداة سطر أوامر بتقرا ملفات CSV متعددة من فولدر، تنظّفها، تدمجها مع ملف العملاء،
ترفض الصفوف المكسورة بالاسم والسبب، تحسب الإجماليات، وتصدّر النتيجة CSV وExcel
وJSON — مع لوج لكل خطوة واختبارات pytest.

## التسطيب

```
python3 -m venv .venv
source .venv/bin/activate
pip install pandas openpyxl pytest
```

## التشغيل

```
python3 run_etl.py --config config.json
```

تغيير المدخلات أو مكان الإخراج من غير ما تلمس الكود:

```
python3 run_etl.py --config config.json --input-dir data/raw2 --out-dir out2
```

## الإعدادات (config.json)

- input_dir / input_glob: فولدر ملفات الأوردرات ونمط أسمائها
- customers_file: ملف العملاء جوه فولدر الإدخال
- out_dir: مكان المخرجات
- log_file: ملف اللوج (بيتحط جوه out_dir)
- rules: قواعد القبول (أقل وأكتر كمية، أقل سعر)

## المخرجات

- out/orders_clean.csv: الصفوف المقبولة بعد التنضيف والدمج وحساب الإجمالي
- out/rejected.csv: الصفوف المرفوضة مع سبب كل رفض
- out/monthly_totals.xlsx: شيت إجماليات شهرية + شيت لكل عميل
- out/summary.json: ملخص الأرقام (مقبول/مرفوض/إيراد)
- out/etl.log: لوج كامل بالتوقيت

## سياسة الرفض

قواعد القبول ثلاثة: كمية رقم وفي الحدود، سعر موجود وفوق الحد الأدنى، وعميل
موجود في ملف العملاء. الصف اللي بيكسر قاعدة بيترفض باسمه وسببه في اللوج وفي
rejected.csv، والدفعة النضيفة بتكمل. الملخص بيعد المقبول والمرفوض صراحة —
مفيش نجاح جزئي متنكر. لو مفيش ولا صف اتقبل، مفيش ملفات إخراج وكود الخروج 1.

## حدود معروفة

- تكرار رقم الأوردر بقيم مختلفة مش مرفوض (الحذف بيشيل التكرار الحرفي بس بعد شيل المسافات).
- التاريخ بيتحوّل بصيغة ثابتة YYYY-MM-DD؛ قيمة تاريخ مكسورة خطأ قاتل (كود 2) مش صف مرفوض.
- مفيش فحص للأعمدة الناقصة في ملف الإدخال؛ عمود ناقص خطأ قاتل (كود 2).
- أرقام العملاء في ملف العملاء مفترض إنها فريدة.

## أكواد الخروج

- 0: اكتمل وفيه صفوف مقبولة
- 1: اكتمل لكن مفيش أي صف مقبول (مفيش ملفات إخراج)
- 2: خطأ قاتل (إعدادات ناقصة أو إدخال مش موجود) والتريس باك في اللوج

## الاختبارات

```
python3 -m pytest tests/ -v
```

## هيكل المشروع

- run_etl.py: نقطة التشغيل ووسائط سطر الأوامر
- etl/ingest.py: قراءة الفولدر وملف العملاء
- etl/clean.py: التنضيف (مسافات، تكرار حرفي، تحويل أنواع)
- etl/validate.py: قواعد القبول والرفض بالسبب
- etl/transform.py: الحسابات والتجميعات
- etl/export.py: كتابة CSV وExcel وJSON
- etl/pipeline.py: التجميعة
- etl/logging_setup.py: إعداد اللوجينج
- etl/errors.py: الأخطاء المخصوصة
- tests/test_etl.py: الاختبارات
