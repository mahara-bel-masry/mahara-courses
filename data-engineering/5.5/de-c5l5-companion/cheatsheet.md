# ورقة مرجع دوكر - درس DE5.5

## المفاهيم
| المصطلح | هو إيه | التشبيه |
| --- | --- | --- |
| Dockerfile | ملف نصي فيه تعليمات البيئة سطر سطر | الوصفة |
| image | ناتج البناء: نسخة جاهزة مقروءة بس | الطبق المخزن |
| container | الإيميج وهو شغال: عملية حية مستقلة | الأكلة على السفرة |

## أسطر الDockerfile
| السطر | معناه |
| --- | --- |
| `FROM python:3.12-slim` | نبدأ من إيميج أساس جاهز |
| `WORKDIR /app` | مجلد شغل التعليمات اللي بعده، وبيخلقه جوه الإيميج لو مش موجود |
| `COPY sales_report.py sales.csv ./` | نقل ملفات من جهازك لجوه الإيميج |
| `CMD ["python3", "sales_report.py"]` | الأمر الافتراضي عند تشغيل الكونتينر |

## الأوامر
| الأمر | بيعمل إيه |
| --- | --- |
| `docker build -t sales-report .` | يبني إيميج من الDockerfile في المجلد الحالي ويسميه |
| `docker images` | يعد الإيميجات الموجودة |
| `docker run --rm sales-report` | يخلق كونتينر ويشغله ويمسحه بعد الخلاص |
| `docker run --name run1 sales-report` | تشغيل باسم ثابت عشان نرجعله |
| `docker run --network=none sales-report` | تشغيل معزول عن الشبكة |
| `docker run --rm sales-report python3 --version` | تشغيل بأمر مختلف عن الCMD الافتراضي |
| `docker ps` | الكونتينرات الشغالة دلوقتي |
| `docker ps -a` | كل الكونتينرات حتى اللي خلصت |
| `docker container rm run1 run2` | مسح كونتينرات خلصت |
| `docker rmi sales-report` | مسح إيميج، وبيرفض لو في كونتينر مبني منه، شغال أو واقف، إلا بـ`--force` |
| `docker image prune -f` | مسح الإيميجات المعلقة اللي مالهاش اسم |
| `docker pull python:3.12-slim` | سحب إيميج من Docker Hub |

## قاعدة الcache
التعليمات اللي بتغير الملفات (زي COPY وRUN) بتطلع طبقة layer جديدة، وWORKDIR ممكن يضيف مجلد للإيميج، والوصفية الخالصة (زي CMD) بتتسجل كإعدادات. كل خطوة بتتخزن في الcache، ولو إدخال خطوة اتغير: الخطوة دي وكل اللي بعدها بيتبنوا من جديد، واللي قبلها بيفضل مخزن. رتب الDockerfile: الثابت في الأول والمتغير في الآخر.
