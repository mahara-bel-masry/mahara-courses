# مرفق درس دوكر من الصفر - DE5.5

الملفات دي هي نفسها اللي اتنفذت في الدرس، جاهزة تجربها على جهازك.

## الملفات
- `sales_report.py` : سكربت تقرير المبيعات (بايثون ستاندرد ليبراري بس، مفيش تسطيب مكتبات)
- `sales.csv` : بيانات المبيعات التجريبية
- `Dockerfile` : وصفة البناء، أربع أسطر
- `session.txt` : نص جلسة التنفيذ كاملة بكل الأوامر والنواتج الحقيقية
- `exercises.md` + `exercises-session.txt` : التمارين وحلولها المنفذة فعلًا
- `cheatsheet.md` : ورقة مرجع بأوامر الدرس

## تجرب من الأول على جهازك
المتطلب الوحيد: Docker Engine متسطب وشغال (Docker Desktop على ويندوز وماك، أو حزمة دوكر على لينكس).

```bash
cd مجلد-الملفات
docker build -t sales-report .
docker run --rm sales-report
```

هتلاقي نفس الناتج اللي في الدرس: سبعة أوردرات اتقراوا، خمسة بعد شيل التكرار، تلاتة مؤكدين، إجمالي ألف وربعمية جنيه.

## فروق بيئة التسجيل عن جهازك (للصدق الكامل)
- الإيميج الأساسي `python:3.12-slim` كان متجهز مسبقًا في بيئة التدريب؛ على جهازك أول بناء هيسحبه من Docker Hub أوتوماتيك، وممكن تسحبه بنفسك: `docker pull python:3.12-slim`
- في التسجيل شغلنا الكونتينرات بعلم `--network=none` كعزل شبكي إضافي؛ الأمر الأساسي على جهازك مش محتاجه
- النواتج في الجلسات المرفقة حقيقية من تنفيذ فعلي على محرك Docker Engine إصدار 27، مش معادة الكتابة ولا متظبطة
