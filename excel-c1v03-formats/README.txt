Excel C1 video 3 lesson files (number, date and time formats, custom formats, regional settings).
Run everything from THIS folder (the one that holds assets, run, data, lab). Paths inside the scripts are relative.
Setup: Python 3.13, then: pip install openpyxl==3.1.5 ; LibreOffice 26.8.3.1 (soffice on PATH) is used to display the formatted cells (CSV export "as shown"). Logged version: run/versions.out.
Example: python assets/formats.py   (compare the printed output with run/formats.out)
Lab: python lab/make_lab.py ; solution: python lab/make_solution.py ; logs in run/lab.out and run/solution.out
Versions used: run/versions.out. All results were produced with Python and LibreOffice, not Microsoft Excel. All data is made up.
Colours in formats (Red, Blue) are not visible in a CSV export, so they are documented only (Microsoft page), not tested.
The first sentence of the video (opening line) is in script/00-opening-line.txt.
